# 🎨 SnapMint Studio — Exact KB & MB Photo, Signature & Document Resizer

**Live Tool:** [https://hiralalapplyfastai.github.io/snapmint-studio/](https://hiralalapplyfastai.github.io/snapmint-studio/)

**SnapMint Studio** is a fast, free, browser-based image compression and resizing tool built to resize **passport photographs, handwritten signatures, ID cards, and scanned certificates** to exact **KB or MB** file size limits (`20 KB`, `50 KB`, `100 KB`, `250 KB`, `1 MB`, or any custom target) without losing clarity.

---

## ✨ Key Features

- **Exact KB & MB Precision:** Match strict file size requirements for online exam forms, job recruitment portals, and document uploads.
- **100% On-Device Privacy:** All processing runs locally inside your web browser using HTML5 Canvas — **zero server uploads**, zero data storage.
- **One-Click Quick Presets:** Instant presets for `20 KB`, `50 KB`, `100 KB`, `250 KB`, and `1 MB`.
- **Standard Dimension Presets:**
  - **Original Ratio:** Best clarity while hitting exact file size targets
  - **Passport Photo:** `300 × 360 px`
  - **Signature:** `240 × 90 px`
- **Multiple Output Formats:** Export directly to **JPG / JPEG**, **WEBP**, or **PNG**, with built-in image rotation (`0°`, `90°`, `180°`, `270°`).
- **Mobile & Desktop Friendly:** Works smoothly on Android, iPhone, Windows, and Mac browsers without installing any app.

## 🚀 How to Use

1. Open **[SnapMint Studio](https://hiralalapplyfastai.github.io/snapmint-studio/)**.
2. Click **Choose Image File** (or drag and drop your JPG, PNG, or WEBP image).
3. Select a quick preset (`20 KB`, `50 KB`, `100 KB`, `250 KB`, `1 MB`) or enter a custom target size.
4. Click **Compress & Resize Now**, verify the output size and preview, and tap **Download Resized Image**.
